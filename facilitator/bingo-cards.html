BUG HUNT BINGO

Find and fix bugs to complete a row, column, or diagonal!

Print this page (Ctrl/Cmd+P) for paper cards. Cut along card borders.

How to Play

  • Each team gets one bingo card and access to the buggy calculator app
  • Run the app: npm run dev
  • Find and fix bugs in the codebase. Each bug you fix can mark off a matching square
  • Each bug can only be used for ONE square (choose wisely!)
  • First team to complete a row, column, or diagonal wins!
  • Mark squares with a pen or highlighter as you complete them

Square Rules

  • Fix a bug using Grep - Show that you used a search tool (grep, Ctrl+F, Claude's search) to locate the bug
  • Fix a bug + add a test - Write a test that would have caught this bug
  • Explain a bug to another team - Walk over and explain it clearly (they confirm understanding)
  • Fix a bug in under 90 seconds - Timed by a teammate from discovery to working fix
  • Use Claude to suggest a fix - Ask Claude Code and apply its suggestion
  • Find a bug by reading a stack trace - The bug produces a runtime error, NaN, or Infinity that leads you to the cause
  • Fix a typo or syntax bug - A bug caused by a misspelling or syntax mistake
  • Fix a logic bug - A bug in program logic (not just a typo)
  • Prevent a bug with input validation - The fix involves adding a validation check
  • Find a bug without running the app - Spot it by reading code alone, before testing
  • Fix a bug in a utility function - The bug is in the utils/ directory
  • Fix two bugs in the same file - Find and fix two different bugs in one file
  • Find a bug that causes NaN - The bug makes the display show NaN
  • Pair-fix with another team - Collaborate with someone from a different team to fix it
